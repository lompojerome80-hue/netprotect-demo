Fonctionnalités

Un filtre qui travaille même quand l'enfant est seul

NetProtect agit au niveau du réseau : impossible de contourner le filtre en ouvrant un autre navigateur ou une autre application.

Filtrage réseau (DNS)

Le filtre s'applique à tout le téléphone : navigateur, réseaux sociaux, applications tierces.

Recherches bloquées

Les mots-clés sensibles sont filtrés dans les moteurs de recherche, sur tous les navigateurs.

Activation par code

Une licence par téléphone. Activation immédiate avec le code reçu sur WhatsApp.

Protection VPN

Une connexion chiffrée et filtrée est établie tant que la protection est active.

Simple pour l'enfant

L'enfant navigue normalement. Aucun mot de passe demandé, aucune manipulation technique.

Maîtrisé par le parent

Vous restez le seul à pouvoir activer ou désactiver la protection sur l'appareil.

Questions fréquentes

Ce qu'il faut savoir avant de commander

Sur quels téléphones NetProtect fonctionne-t-il ?

Sur les téléphones Android version 8.0 ou plus récente. L'application s'installe sous forme de fichier APK.

Un abonnement mensuel est-il nécessaire ?

Non. Votre licence est valable un an, sans renouvellement automatique ni paiement récurrent.

L'enfant peut-il contourner le filtre ?

Le filtre agit au niveau du réseau (DNS) : il s'applique quel que soit le navigateur ou l'application utilisée.

Comment reçois-je ma licence ?

Par WhatsApp : vous recevez le lien de téléchargement de l'application et votre code d'activation.

Puis-je transférer ma licence sur un autre téléphone ?

Oui, contactez-nous sur WhatsApp : nous désactivons l'ancien appareil et réactivons votre code sur le nouveau.
