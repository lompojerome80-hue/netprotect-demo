L'application

Une application legere, invisible pour l'enfant

NetProtect tourne en arriere-plan sur le telephone. L'enfant ouvre ses applications habituelles : rien ne change a l'ecran, mais tout contenu sensible est bloque avant meme de s'afficher.

  • Interface unique : un ecran d'etat, un bouton, votre code.
  • Aucune identite a creer pour l'enfant, aucun mot de passe a memoriser.
  • Seul le parent active ou desactive la protection.
  • Consommation de batterie tres faible : le filtre tourne dans le reseau.
  • Desinstallation simple : la licence peut etre transferee sur un autre telephone.

Ce qu'elle fait

Un filtre qui travaille même quand l'enfant est seul

NetProtect agit au niveau du réseau : impossible de contourner le filtre en ouvrant un autre navigateur ou une autre application.

Filtrage réseau (DNS)

Le filtre s'applique à tout le téléphone : navigateur, réseaux sociaux, applications tierces.

Recherches filtrées

Les mots-clés sensibles sont bloqués dans les moteurs de recherche, sur tous les navigateurs.

Page « bloque » claire

Plutôt qu'une erreur incomprehensible, l'enfant voit une page explicite : ce contenu est bloque.

Activation par code

Une licence à vie par téléphone. Activation immédiate avec le code reçu sur WhatsApp.

Protection VPN

Une connexion chiffrée et filtrée est établie tant que la protection est active.

Controle parental

Vous restez le seul à pouvoir activer ou désactiver la protection sur l'appareil.

Effet immédiat

Le filtre agit dès la première connexion : aucune latence ressentie par l'enfant.

Conçu pour Android

Optimisé pour les téléphones et tablettes Android 8 ou supérieurs.

Aucune donnée collectée

Aucun historique envoyé, aucun compte requis : tout reste sur le téléphone.

Adultes

Les adultes peuvent aussi l'utiliser

NetProtect n'est pas reserve aux enfants. Tout adulte qui souhaite se proteger des contenus pour adultes peut installer l'application sur son propre telephone : elle bloque alors automatiquement les sites et les recherches sensibles, sans que vous ayez a y renoncer.

Un filtre volontaire, pour vous

Vous decidez de filtrer votre propre appareil : le filtre s'applique a tous vos navigateurs et applications, comme pour un enfant, mais vous restez le seul utilisateur.

Protection contre les contenus indesirables

Contre les contenus pour adultes, les pages trompeuses et les recherches induites : un rempart supplementaire, activable en permanence ou par periods.

Questions frequentes

Ce qu'il faut savoir avant de commander

Sur quels telephones NetProtect fonctionne-t-il ?

Sur les telephones et tablettes Android version 8.0 ou plus recente. L'application s'installe sous forme de fichier APK.

Un abonnement mensuel est-il necessaire ?

Non. Votre licence est valable à vie, sans renouvellement ni paiement recurrent.

L'enfant peut-il contourner le filtre ?

Le filtre agit au niveau du reseau : il s'applique quel que soit le navigateur ou l'application utilisee.

Comment recois-je ma licence ?

Par WhatsApp : vous recevez le lien de telechargement de l'application et votre code d'activation.

Puis-je transférer ma licence sur un autre telephone ?

Oui, contactez-nous sur WhatsApp : nous desactivons l'ancien appareil et reactivons votre code sur le nouveau.
